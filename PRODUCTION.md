# Production System

## Obiettivo

Creare contenuti coerenti senza trasformare ogni Reel in un piccolo progetto video.

Target:
- setup rapido;
- qualità sufficiente;
- stile riconoscibile;
- batch production;
- massimo riuso dei template.

## Production corner

### Piano

Preferenza:
- scrivania o tavolo stabile;
- superficie opaca;
- colore neutro scuro o medio;
- niente texture troppo aggressive.

Un semplice pannello/cartoncino opaco può bastare.

### Smartphone

Serve un supporto che permetta:
- ripresa verticale 9:16;
- top-down stabile;
- regolazione altezza;
- ripetibilità dell'inquadratura.

### Luce

Partenza consigliata:
- una luce morbida principale laterale a circa 45°;
- luce ambiente controllata;
- evitare luce diretta sopra copertine lucide.

Seconda luce solo se realmente necessaria.

### Audio

Nella fase iniziale:
- nessun microfono necessario se il narrato viene generato in TTS;
- eventuale audio ambiente solo come dettaglio creativo.

## Shot list standard

Per ogni fumetto registrare, quando utili:

1. cover frontale;
2. retro;
3. costa;
4. apertura lenta;
5. 2-3 dettagli interni;
6. eventuali difetti;
7. dettaglio logo/editore/numero;
8. ripresa mani;
9. eventuale bag & board;
10. clip finale di archiviazione.

Durata clip:
3-6 secondi ciascuna.

## Batch workflow

Una sessione dovrebbe coprire 3-5 fumetti.

### Prima della sessione

Per ogni pezzo:
- scegliere format;
- definire hook;
- raccogliere dati;
- preparare script breve.

### Registrazione

Registrare tutte le clip in blocco.

### Post-produzione

Usare template fissi per:
- intro;
- lower thirds;
- prezzo;
- verdict;
- outro;
- sottotitoli.

## File naming

Formato consigliato:

`YYYY-MM-DD_FORMAT_SUBJECT_SHOT.ext`

Esempio:

`2026-09-24_NEW-IN-VAULT_BATMAN-01_COVER.mp4`

## Cartelle consigliate

```
content/
  raw/
  projects/
  exports/
  thumbnails/
  scripts/
  published/
```

I file video non devono necessariamente essere versionati in Git.

GitHub conserva:
- regole;
- script;
- template testuali;
- decisioni;
- analytics sintetici.

## Tempo target

Sessione settimanale:

- 20-30 min: selezione e script;
- 45-60 min: riprese in batch;
- 60-90 min: montaggio e scheduling;
- 15 min: review analytics.

Target complessivo:
circa 3 ore/settimana.

## Automazione

Da automatizzare:
- bozza script;
- TTS;
- sottotitoli;
- caption;
- template;
- naming;
- checklist;
- raccolta metriche, dove possibile.

Da non automatizzare completamente:
- scelta del fumetto;
- opinione editoriale;
- valutazione dell'acquisto;
- selezione finale delle clip;
- decisione su cosa pubblicare.

## Regola qualità

Pubblicare un contenuto buono e coerente è meglio che rimandarlo per cercare una qualità cinematografica non necessaria.
